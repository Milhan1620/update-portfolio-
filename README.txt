HOW TO RUN IN VS CODE
1. Unzip, then File > Open Folder > select "portfolio".
2. Install the "Live Server" extension, right-click index.html > Open with Live Server.
   (Or just double-click index.html.)
3. To change the picture, replace assets/photo.png with a transparent PNG.
4. Copy your CV into this folder as Milhan_Musharaf_CV.pdf so the Download CV button works.
